# Calculator Web App

A modern and responsive calculator built using HTML, CSS, and JavaScript.

## Features

✅ Basic arithmetic operations (+, −, ×, ÷)  
✅ Real-time result display  
✅ Clear screen functionality  
✅ Calculation history panel  
✅ Click history to reuse calculations  
✅ Keyboard support  
✅ Glassmorphism UI design  
✅ Responsive layout  

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Preview

A stylish calculator interface with a display screen, operation buttons, and a history panel to store previous calculations.

## Learning Outcomes

- DOM manipulation
- Event handling
- Keyboard support
- Responsive web design
